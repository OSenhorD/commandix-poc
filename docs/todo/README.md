# docs/todo/

Registro de melhorias possíveis, erros encontrados e acoplamentos percebidos durante o desenvolvimento — coisas que **não bloqueiam** a entrega atual, mas que não devem ser esquecidas.

Um arquivo por item: `docs/todo/<slug>.md`.

## Formato sugerido

```markdown
# <título curto>

**Contexto:** onde/quando foi percebido (entrega, arquivo, linha)
**Descrição:** o que é o problema ou a melhoria
**Impacto:** por que importa (dívida técnica, risco, custo de manutenção)
**Sugestão:** encaminhamento proposto, se houver
```

## Quando criar um item

- Durante qualquer tarefa, ao perceber algo fora do escopo da entrega atual: duplicação, acoplamento indevido, gap de teste, decisão técnica discutível, débito técnico.
- Não é para bugs bloqueantes da tarefa em andamento — esses se corrigem na hora.
- Ver [`AGENTS.md`](../../AGENTS.md) § Fluxo de trabalho sugerido para IA.
